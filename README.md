# ORIONINSIST Digital Production

JSON-driven social media image production with **Python, uv, and Typst**.

**Current status:** PNG generation is available. PDF, slides, and video are planned.

## Quick start

```bash
uv run render.py content/work-smarter.json instagram_post
```

This creates `output/instagram_post.png`. Generated files in `output/` are not committed to GitHub.
