# ORIONINSIST | Digital Production

Local-first, native-tool-based digital production.

**One Content Source. Independent Tools. Reusable Templates. One Command.**

## Structure

- `tools/` — Each native tool has its own independent workspace.
- `tools/typst/` — Typst workspace (initially empty).

Tool-specific setup, documentation, templates and production workflows will be added incrementally.

Project management remains in the original **ORIONINSIST | Digital Production** Google Sheets workbook. This repository contains source files, not management duplicates.
